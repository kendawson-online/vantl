JSON Error Handling

This demo intentionally points to a missing JSON file to show the built-in error UI. The timeline stays visible with a friendly message instead of breaking.

What to expect

  • A red inline error appears because the JSON endpoint is missing.
  • The page does not crash; you can fix the URL and reload.
  • Caching: if you change JSON content, update lastupdated to invalidate cached data.

Config snippet


<div class="timeline"
     data-json-config="../../assets/data/does-not-exist.json">
  <div class="timeline__wrap">
    <div class="timeline__items"></div>
  </div>
</div>
